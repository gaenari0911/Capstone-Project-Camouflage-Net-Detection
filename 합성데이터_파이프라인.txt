--------------------------------------------------

[4] JPG mask → YOLO segmentation txt 변환

각 이미지마다 수행:

1. mask jpg 읽기
2. threshold 128 기준 이진화
3. contour 추출
4. polygon 생성
5. 좌표를 0~1 범위로 정규화
6. .txt 파일 저장

결과 저장:

converted/
 ├── images/
 └── labels/

결과:
모든 이미지에 대응하는 YOLO 형식 txt 라벨 생성

--------------------------------------------------

[5] 기존 데이터 train / val / test 분리

규칙:

- Training (700장) → train
- Testing (300장)
    → 100장: val
    → 200장: test

조건:

- 초록/갈색 : 설원 = 7 : 3 유지
- 랜덤이 아니라 분포 기반 샘플링

결과:

images/train → 700
images/val   → 100
images/test  → 200

labels도 동일하게 이동

--------------------------------------------------

[10] 합성 데이터 생성

목표:
위장망 포함 이미지 5300장 생성

과정:

1. 기존 mask 기반 객체 crop
2. 배경 랜덤 선택
3. 랜덤 위치에 배치
4. blending 수행
   - alpha blending
   - edge blur
   - color matching
5. 새로운 mask 생성
6. polygon → txt 변환

저장:

images/train/
labels/train/

--------------------------------------------------

[11] 최종 데이터 수
