# 실험 이름·지표 읽기 사전

보고서와 데모를 처음 읽을 때 필요한 설정표입니다. 새 실험이 아니라 완료된 v5 결과의 설명 자료이며, 기존 수치·예측·checkpoint는 바꾸지 않았습니다.

## 1. 이름부터 읽기

| 표기 | 뜻 | 알아볼 질문 |
| --- | --- | --- |
| M · Main | 실제 train 748장을 모두 사용 | 어떤 합성 전략이 도움이 되는가? |
| L · Low-data | 동일한 고정 실제 187장, 즉 25% 사용 | 실제 데이터 부족을 합성으로 보완하는가? |
| A · Ablation | 휴리스틱 합성의 선택 점수를 하나씩 제외 | 어떤 점수가 도움이 되는가? |
| H · Head ablation | boundary 보조 학습 구성을 변경 | 보조 head/loss가 도움이 되는가? |
| BG · Background | 객체가 없는 별도 배경 학습 이미지 추가 | 오탐과 미탐이 어떻게 달라지는가? |
| S4 / S3 | 1학기 보관 실험 이름 | 과거 실제+배경 / 실제+합성+배경 결과는? |

G0라는 정식 실험명은 없습니다. 배경 추가 조건을 말씀하신 것이라면 **BG0**입니다. S3/S4라는 과거 실험명은 프로젝트 진행 단계 S3/S4와도 구분합니다.

**M2_seed0** 읽는 법: M=실제748, 2=AnyDoor 무작위 선택 합성3000 추가, seed0=학습 난수번호0입니다. H2 구조로150epochs 학습한 뒤 Validation-best checkpoint를 사용합니다. 숫자2는 GPU 번호·seed 수·모델 크기가 아닙니다.

M/L의 끝 번호는 0=실제만, 1=휴리스틱, 2=AnyDoor random, 3=AnyDoor task-aware입니다. 다른 실험군에는 이 규칙을 적용하지 않습니다. 특히 **A5는 AnyDoor가 아니며, H2는 M2와 다른 의미**입니다.

## 3. 데이터와 모델: 서로 다른 두 축

M/L/A/BG는 주로 **어떤 데이터로 학습했는지**를 나타내고, 기본 모델은 H2입니다. H0/H1/H2는 **어떤 보조 head/loss를 사용했는지**를 나타냅니다.

| 구조 | 쉽게 설명 | 추론 시 주의 |
| --- | --- | --- |
| H0 | 공통 segmentation 모델만 학습 | boundary 보조 branch 없음 |
| H1 | segmentation + 일반 boundary BCE 보조 학습 | 추론은 segmentation 출력 사용 |
| H2 | segmentation + 거리 가중 boundary BCE 보조 학습 | 추론에서 두 mask를 융합하는 방식이 아님 |

현재 기본 H2는 custom DualHeadSegment n-scale입니다. n은 모델 크기 계열입니다. pretrained 파일 이름의 m을 보고 실제 모델도 m-scale이라고 해석하지 않습니다.

휴리스틱은 실제 객체를 배경에 합성하고 Tone(색조), Texture(질감), Edge(경계), Placement(배치) 등의 선택 점수로 후보를 고르는 방식입니다. A2~A5는 해당 **선택 점수**를 제외한 것이지 색상 보정이나 blending을 통째로 제거한 실험이 아닙니다.

AnyDoor는 객체 참조와 배치 정보를 조건으로 새 합성 이미지를 생성합니다. M/L 각각6,000장 후보에서 random과 task-aware가 각각3,000장을 선택합니다. Task-aware는 Judge 모델이 어렵다고 판단한 후보를 선호하는 선택 전략이지 더 우수한 데이터라는 보장이 아닙니다. Judge는 후보를 채점하는 모델이고, learner는 선택된 데이터로 독립 학습하는 최종 모델입니다.

L의 합성 객체 출처와 Judge의 실제 학습 정보는 고정187장으로 제한했습니다. 외부 배경·pretrained·생성 모델까지 모두187장으로 만들었다는 뜻은 아닙니다. 휴리스틱21,000장 + AnyDoor12,000장 = 생성33,000장입니다. 같은 후보를 두 방식으로 선택한 것을 추가 생성으로 중복 계산하지 않습니다.

## 4. 어떤 두 조건을 비교해야 하나?

| 비교 | 바뀌는 내용 | 비교가 답하는 질문 |
| --- | --- | --- |
| M0 ↔ M1 / M2 / M3 | 실제748에 합성 전략 추가 | 전체 실제 데이터에서 합성이 유효한가? |
| L0 ↔ L1 / L2 / L3 | 실제187에 합성 전략 추가 | 실제 부족 상황을 보완하는가? |
| M2 ↔ M3, L2 ↔ L3 | 같은 AnyDoor 후보의 선택 방식 | 난도 기반 선택이 무작위보다 좋은가? |
| M0 ↔ BG0, M1 ↔ BG1 | 같은 배경2129장 추가 | background-only의 영향은? |
| A1 ↔ A2~A5 | 휴리스틱 선택 점수 하나 제거 | 각 점수의 기여는? 40epoch Val-only |
| H0_R ↔ H1_R ↔ H2_R | 실제-only에서 head/loss 변경 | 보조 boundary 학습의 기여는? |
| H0_S ↔ H1_S ↔ H2_S | 합성 혼합에서 head/loss 변경 | 합성이 있어도 구조 효과가 같은가? |

**Background 2×2**는 아래 네 칸입니다. BG0↔BG1만 보면 합성 추가 효과이며, background 자체의 효과는 M0↔BG0와 M1↔BG1로 봅니다.

| 조건 | 배경-only 없음 | 같은 배경-only 2129장 있음 |
| --- | --- | --- |
| 휴리스틱 합성 없음 | M0: 실제748 | BG0: 실제748 + 배경2129 |
| 휴리스틱 합성3000 있음 | M1: 실제748 + 합성3000 | BG1: 실제748 + 합성3000 + 배경2129 |

배경-only는 정답 객체 라벨이 없는 **별도 학습 이미지**입니다. 합성 이미지 안에서 객체 뒤에 깔리는 배경과 다릅니다. BG0/BG1은 배경의 절대 장수는 같지만 비율은74.00%/36.23%로 다릅니다. 모든 배경 이미지를 새로 독립 주석 검수했다는 뜻도 아닙니다.

## 5. 지표를 읽는 법

| 이름 | 쉬운 의미 | 좋은 방향 / 주의 |
| --- | --- | --- |
| Mask mAP50–95 | 객체별 분할 검출 AP를 IoU 기준0.50~0.95에서 평균 | 높을수록 좋음. 핵심 종합 지표. 픽셀 정확도나 평균 IoU가 아님 |
| Mask mAP50 | IoU0.50 기준에서의 분할 검출 AP | 높을수록 좋음. 더 느슨한 기준이라 mAP50–95보다 보통 높음 |
| Box mAP | mask 대신 사각형 bbox로 평가한 AP | Mask mAP와 별도 지표 |
| Precision · 정밀도 | 예측한 객체 중 맞은 비율: TP/(TP+FP) | 높을수록 좋음. 적게 예측하면 Recall이 낮아질 수 있음 |
| Recall · 재현율 | 실제 객체 중 찾은 비율: TP/(TP+FN) | 높을수록 좋음. 놓침을 얼마나 줄였는지 확인 |
| F1 | Precision과 Recall의 조화평균 | 높을수록 좋음. mAP와 계산 방식이 다름 |
| TP / FP / FN | 맞게 찾음 / 잘못 검출 / 놓침 | TP는 높고 FP/FN은 낮을수록 좋음. 객체 단위 개수 |
| FP/image | 한 이미지당 잘못 검출한 객체 수 | 낮을수록 좋음. background-only holdout의 FPR은 아님 |
| Union IoU · 데모 | 이미지 내 mask를 합친 뒤 겹침/합집합 | 0~1, 높을수록 좋음. 한 이미지 설명용이며 공식 mAP가 아님 |
| Confidence | 예측에 붙는 모델 점수 | 정답 확률의 보장이나 실제 성능 수치가 아님 |
| ± SD | 독립 학습 seed3개의 표본 표준편차 | Test 표본 신뢰구간이 아니며 통계적 유의성을 뜻하지 않음 |
| pp | 두 백분율 수치의 뺄셈, percentage points | 21.03→29.14는 +8.11pp. 상대8.11% 증가와 다름 |
| Loss | 학습 중 최소화하는 목적 함수 값 | 보통 낮아지는지 참고. loss만으로 모델 우열을 정하지 않음 |

보고서의 AP/P/R/F1은 원래0~1값에100을 곱해 표시합니다. 예: Mask mAP31.99는 이미지31.99%를 맞혔다는 뜻이 아닙니다. 데모 Union IoU0.916은 그 이미지의 합친 영역 겹침91.6%이며 Test 평균 성능이 아닙니다.

현재 Mask P/R/F1은 confidence0.25, mask IoU0.5에서 객체를 매칭합니다. 공식 AP 계산에는 confidence floor0.001을 사용합니다. NMS IoU0.7은 겹치는 예측을 정리하는 기준으로, 정답 매칭 IoU0.5와 다른 값입니다. 1학기 P/R/F1은 Box 기준이므로 현재 Mask P/R/F1과 바로 섞어 비교하지 않습니다.

## 6. 데모 색상·숫자와 읽는 순서

차이 모드: 초록=정답과 예측의 겹침, 주황=정답만 있는 영역, 분홍=예측만 있는 영역입니다. 이 색은 **픽셀 영역** 차이이며 객체 단위 TP/FP/FN과 일대일 대응하지 않습니다. Overlay 모드: 초록 윤곽=정답, 파란 영역=예측입니다. 원본 모드는 색을 표시하지 않습니다.

1. 선택한 모델 설명에서 실제/합성/배경 장수를 확인합니다.
2. 같은 Test 이미지를 놓고 왼쪽과 오른쪽만 바꿉니다. 처음에는 M0↔M2, 다음은 M1↔BG1을 권합니다.
3. 놓친 영역(주황)과 과도한 예측(분홍), 객체 TP/FP/FN을 함께 봅니다.
4. 정답 영역 확대 후에는 전체 이미지로 돌아와 바깥쪽 오탐도 확인합니다. 표시되는 수치는 확대 전 전체 이미지 기준입니다.
5. 좋은 사례만 결론으로 삼지 말고 악화·임의·공통 실패 사례와 전체 Test 표를 함께 봅니다.

데모는 고정 seed0 모델10개의 실제 저장 예측을 재생합니다. 보고서의 M/L/BG 표는3seed 평균입니다. 화면에서 보이는 두 모델 차이를 seed 분산이라고 부르지 않습니다. Union IoU는 객체를 합치므로 중복 검출 문제를 숨길 수 있어 객체별 FP도 함께 봅니다. 표시 mask는 평가에 사용한160×160 격자를640×640로 확대한 것입니다.

전체 폴더를 내려받으면 HTML·사전·저장 예측 비교는 SSH/인터넷/GPU 없이 열립니다. 새 이미지 추론만 서버/GPU 및 원격 접속 시 SSH 터널이 필요합니다. 새 이미지에는 정답이 없어 IoU를 표시하지 않습니다.

## 7. 학습 곡선·seed·평가를 읽을 때

Train은 학습 데이터, Validation100장은 checkpoint 선택용, Test200장은 최종 고정 모델 평가용입니다. Validation-best는 마지막 epoch가 아니라 Validation mask mAP가 가장 높았던 checkpoint입니다. Test 성능으로 seed나 checkpoint를 고르지 않았습니다.

epoch는 학습 데이터를 한 번 도는 단위이고 batch16은 한 번에 처리하는 이미지 수입니다. 현재 기본 recipe는 입력640, AdamW, lr0=0.001, lrf=0.01, warmup3, cosine, EMA/early stopping 없음입니다. A는40epochs, 나머지 현재 실험은150epochs입니다. H만 모델 구성을 바꿉니다.

seed0/1/2는 난수 설정을 바꿔 독립 학습을3번 한 것입니다. 데이터를3등분하거나 이전 모델을 이어 학습한 것이 아닙니다. 같은 데이터 조건 안에서는 데이터/분할을 공유합니다. 1학기 hard mining3loop와도 다릅니다.

**같은150epochs가 같은 계산량을 뜻하지는 않습니다.** 실제 기록의 seed당 update는 M0=7,050, M1~M3=35,250, L0=1,800, L1~L3=30,000, BG0=27,000, BG1=55,200입니다. 따라서 합성 추가 효과에 학습 데이터량·update 증가가 함께 포함됐음을 밝힙니다.

학습 loss만 낮아지고 Validation 성능이 정체/하락하면 과적합 가능성을 살피되 곡선 하나만으로 원인을 확정하지 않습니다. 서로 다른 split의 점수나40epoch A와150epoch M을 동일 조건 결과처럼 비교하지 않습니다.

## 8. 결과 해석에서 넘지 말아야 할 선

합성 추가 개선은 관찰됐지만 task-aware가 random보다 우수하다는 결과는 아닙니다. Full 휴리스틱과 거리 가중 head가 항상 가장 좋다는 결과도 아닙니다. Background는 오탐을 줄였지만 Recall/mAP도 낮췄으므로 전체 성능 향상으로 요약하지 않습니다.

1학기는 같은 모델 계열의 역사적 맥락입니다. 학습 recipe와 데이터 membership 등의 차이가 남아 동일 조건 재현 또는 학기간 직접 우열 비교라고 하지 않습니다. BG 후속은 기존 Test 결과를 확인한 뒤 동일 Test를 재사용한 사후 보완입니다. A/H는 단일seed, 최종 Test는200장이고 장면 단위 독립성 및 합성 mask 독립 주석 감사까지 완전히 증명한 것은 아닙니다.

## 9. 근거와 읽는 순서
